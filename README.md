# MosMedStatistics: Анализ тональности отзывов о медицинских учреждениях Москвы

## О проекте
Проект направлен на мониторинг качества медицинских услуг с помощью анализа тональности отзывов пациентов о медицинских организациях Департамента здравоохранения Москвы (ДЗМ). Используются методы NLP для определения общей тональности отзывов и аспектно-ориентированного анализа.
## Цели
1. Разработать модель для классификации тональности отзывов (положительная, нейтральная, отрицательная).
2. Провести аспектный анализ по ключевым категориям:
  - Ожидание
  - Отношение персонала
  - Благоустройство помещений
  - Приём
  - Эффективность лечения

## Технологии
- **Язык:** Python
- **Библиотеки:** transformers, pyabsa, pandas, numpy, scikit-learn, seaborn, matplotlib
- **Модели:**
  - [RuBERT для анализа тональности](https://huggingface.co/blanchefort/rubert-base-cased-sentiment)
  - [DeBERTa для аспектного анализа](https://huggingface.co/yangheng/deberta-v3-base-absa-v1.1)

## Данные
- Источник: Отзывы с Яндекс.Карт (2023–2025 гг.)
- Выборка: 1098 отзывов по 7 медицинским организациям Москвы
- Предобработка: очистка, лемматизация, удаление стоп-слов, токенизация

## Пример работы модели
**Отзыв:**  
*"отличное место , специалисты хорошие и внимательные , все объясняют , отвечают на все вопросы , персонал отзывчивый и всегда готов помочь , конечно ожидание бывает долгими , даже если по записи , но думаю стоит того , чтобы подождать"*

**Результат:**  
- **Общая тональность**: Позитивная  
- **Аспекты**:  
    - место: Позитивная (уверенность 0.9975)
    - специалисты: Позитивная (уверенность 0.9977)
    - персонал: Позитивная (уверенность 0.9882)
    - ожидание: Негативная (уверенность 0.6316)
