## О проекте
Проект направлен на мониторинг качества медицинских услуг с помощью анализа тональности отзывов пациентов о медицинских организациях Департамента здравоохранения Москвы (ДЗМ). Используются методы NLP для определения общей тональности отзывов и аспектно-ориентированного анализа.
## Цели
1. Разработать модель для классификации тональности отзывов (положительная, нейтральная, отрицательная).
2. Провести аспектный анализ по ключевым категориям:
  - Ожидание
  - Отношение персонала
  - Благоустройство помещений
  - Приём
  - Эффективность лечения

## Технологии
- **Язык:** Python
- **Библиотеки:** transformers, pyabsa, pandas, numpy, scikit-learn, seaborn, matplotlib
- **Модели:**
  - [RuBERT для анализа тональности](https://huggingface.co/blanchefort/rubert-base-cased-sentiment)
  - [DeBERTa для аспектного анализа](https://huggingface.co/yangheng/deberta-v3-base-absa-v1.1)

## Быстрый старт
В файле `example.py` содержиться код для анализа одного или сразу нескольких отзывов:
```python
from medreviewanalyzer import MedicalReviewAnalyzer

# Инициализация анализатора
analyzer = MedicalReviewAnalyzer(verbose=True)

# Анализ одного отзыва
result = analyzer.analyze_review("В клинике чисто, но врач был груб.")
print(result)

# Анализ датасета
import pandas as pd
df = pd.read_excel('example.xlsx')
results = analyzer.analyze_dataframe(df=df)
```

## Данные
- Источник: Отзывы с Яндекс.Карт (2023–2025 гг.)
- Выборка: 1098 отзывов по 7 медицинским организациям Москвы
- Предобработка: очистка, лемматизация, удаление стоп-слов, токенизация

## Пример работы модели
**Отзыв:**  
*"отличное место , специалисты хорошие и внимательные , все объясняют , отвечают на все вопросы , персонал отзывчивый и всегда готов помочь , конечно ожидание бывает долгими , даже если по записи , но думаю стоит того , чтобы подождать"*

**Результат анализа:**

**Общая тональность:** Positive

| Аспект | Тональность | Уверенность | Категория |
|--------|-------------|-------------|-----------|
| место | Positive | 99.8% | отношение к организации |
| специалисты | Positive | 99.8% | отношение к врачу |
| персонал | Positive | 98.8% | отношение к персоналу |
| ожидание | Negative | 63.2% | отношение к записи и времени ожидания |


## Jupyter Notebooks
- `analysis.ipynb` - для сентимент-анализа собранного датасета и формирования excel с отчётом.
- `example.ipynb` - для сентимент-анализа одного отзыва для примера.
- `model_predictions_analysis.ipynb` - для анализа предсказаний модели (расчет метрик, чистка и группировка аспектов, визуализация)
- `aspects_statistics.ipynb` - для сентимент-анализа истинной разметки (чистка и группировка аспектов, визуализация)
